# Decision sheet A: after the thesis, before the judgment sections

Opus fills every answer with a recommended default from the data and the thesis. Steve edits in one pass (mark changes, add notes). The judgment sections are then built once from this sheet: SKU and adjacency, synopsis, library picks, shelf test, packaging hierarchy.

Format per line: Question | Default (Opus) | Basis | Steve

## Positions and pricing
1. Positions to read (shelf sets) and which are HOME, GROWTH, SCOUT
2. Price call per position: hold, target or open, with SRP
3. Banner groups to treat as launch vs hold (from the thesis)

## Current lineup
4. Each existing and launching SKU: keep, lead, watch, or cut
5. If the launch has to be smaller, which SKU is the cut
6. Shopper-facing SKU names (pack name vs what the shopper reads), one line each

## Whitespace and adjacency
7. Flavor whitespace: ranked list, priority, any to drop
8. Pack and format ideas: which to pursue, hold or avoid
9. Adjacent categories: pursue, consider, avoid (with the reason)
10. Hard lines (formats or programs reserved for private label, categories the client will not enter)

## Shelf test
11. Competitor packs to capture (list)
12. Scores per pack: what it is, shelf block, brand read, flavor (1 to 5, halves allowed)
13. Wins and loses per shelf: one line each

## Packaging
14. Hierarchy order on pack (brand, product name, descriptor, flavor)
15. Any elements that are fixed (logo, mark) and not up for change

## Library and synopsis
16. Library picks: which syndicated reads matter to this client
17. Synopsis tone: how hard to lead the reader toward the SKU and adjacency calls
